App 名字：
【MSN Chat Viewer】

App 目的：
【本地瀏覽 MSN 對話記錄 XML 檔案，將對話內容以聊天視覺方式呈現，並提供訊息搜尋功能，重現真實聊天情境】

App 功能與業務邏輯：
功能 1：上傳 XML 對話檔案
業務邏輯：用戶點擊按鈕選擇本地 XML 檔案，系統使用 FileReader API 讀取檔案內容，並解析 XML 結構轉為 JavaScript 資料格式。

功能 2：解析 MSN XML 對話格式
業務邏輯：從 XML 讀取每條訊息（包含發送者、時間、內容），轉換為內部資料結構（例如：陣列或物件），並依時間排序準備渲染。

功能 3：顯示聊天內容（聊天泡泡樣式）
業務邏輯：以聊天室格式呈現訊息，左邊為對方訊息、右邊為自己訊息，依照時間排序逐條顯示。支援換行、表情圖像等常見格式處理。

功能 4：搜尋聊天內容
業務邏輯：使用者輸入關鍵字後，系統在所有訊息中搜尋符合項目，並突顯高亮顯示，同時自動滾動至第一筆結果。

功能 5：重新載入其他檔案
業務邏輯：提供「重新選擇檔案」按鈕，用戶可切換瀏覽不同的 MSN XML 對話紀錄，畫面自動清空並載入新內容。

App 頁面與功能元素：
頁面 1：主畫面（Chat Viewer）
- 選擇並加載本地 MSN XML 對話檔案
- 顯示解析後聊天內容
- 搜尋訊息文字
- 重新選擇其他檔案

UI 元素：
- 標題列（顯示 App 名稱）
- 「選擇檔案」按鈕（使用 input[type="file"]）
- 對話顯示區（scrollable chat window）
- 搜尋欄位（input + 搜尋按鈕）
- 搜尋結果高亮顯示
- 重新載入按鈕
